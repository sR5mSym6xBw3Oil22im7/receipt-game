レシート解析

JPEG / PNG / ZIP のレシート画像を選択してください。ZIPは複数のレシート画像をまとめて解析できます（中身はJPEG/PNGのみ）。

  1. 画像を選ぶ
  2. 解析する
  3. 内容を確認
  4. データベースへ保存

ご注意：選んだ画像は、読み取りのためGoogleのGemini APIへ送信されます。無料枠のAPIを使っているため、送信した内容がGoogleのサービス改善（AIの学習を含む）に使われ、担当者が閲覧することがあります。氏名・電話番号・住所・会員番号・カード番号などが写った画像は選ばないでください。当サイトは画像を保存しません。

「解析」は文字抽出と表示だけを行い、データベースには登録しません。内容を確認後、「データベースへ保存」を押すと解析結果を保存します。
