4. ログ方針

  • Gemini APIが要求を拒否した場合、WARNで HTTPコード、ステータス、メッセージを出力する。
  • Gemini解析が予期せず失敗した場合、ERRORでモデル、MIMEタイプ、画像バイト数、例外クラス、メッセージを出力する。
  • APIキー、画像、解析結果はログに出力しない。
  • local プロファイルでは log/backend.log に出力し、日付と連番でZIP圧縮する（${LOG_FILE}.%d{yyyy-MM-dd}.%i.zip）。
