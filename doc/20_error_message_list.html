4. ログ方針

  • 出力先：標準出力。local プロファイルは log/backend.log（日付と連番で zip にローテーション）。一括処理の結果は log/batch-import.tsv、log/monster-batch.tsv。
  • 残すもの：Geminiの失敗の分類（コード・ステータス）、キーの切替、回転の再解析の失敗、DB障害（スタックトレース）、想定外の例外、個人情報を置換した件数、カードの再点検・下書きの破棄・期限切れルームの削除の件数、別スレッドの処理の拒否・失敗。
  • 残さないもの：APIキー、パスワード、画像、レシートの文字列、置換した個人情報の内容、入力値そのもの。
