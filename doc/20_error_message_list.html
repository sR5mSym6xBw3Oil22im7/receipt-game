400EMPTY_FILE／EMPTY_RECEIPT／INVALID_IMAGE_HASH／FILE_READ_ERROR空ファイル、空データ、ハッシュ不正、読込失敗
400INVALID_ROOM_CODE／INVALID_INDEX／CARD_NOT_IN_HANDルームコード・番号・選択カードが不正
401GEMINI_API_KEY_REJECTEDGeminiがキーを拒否
403SEAT_REQUIRED席トークンなし／不一致／ルームなし（区別しない）
404RECEIPT_NOT_FOUND／ROOM_NOT_FOUND／RESOURCE_NOT_FOUND対象なし
405METHOD_NOT_ALLOWED未対応メソッド
409DUPLICATE_RECEIPT_IMAGE同一画像ハッシュが保存済み
409ROOM_NOT_JOINABLE／NOT_SELECTING／ALREADY_CONFIRMED／ALREADY_FLIPPED／HAND_FULL／SHUFFLE_NOT_ALLOWED／CARD_REMOVED／CARD_IN_USE／ROUND_CHANGED／BATTLE_NOT_READY／REMATCH_NOT_ALLOWEDルーム進行上できない操作
413FILE_TOO_LARGE／IMAGE_TOO_LARGE画像が上限超過
415UNSUPPORTED_MEDIA_TYPEJPEG/PNG以外
422NO_TEXT_FOUND／INVALID_DATA／PERSONAL_INFO_CHECK_FAILED／EMPTY_ANALYSIS_RESULT／INVALID_ANALYSIS_RESULT文字なし、保存不可の値、個人情報の確認失敗、解析結果の不備
429RATE_LIMITED／GEMINI_DAILY_LIMIT／GEMINI_QUOTA_EXCEEDED回数制限、Gemini上限
500INTERNAL_ERROR／UNSAFE_TABLE_NAME予期しない例外（詳細はログのみ）
502GEMINI_API_ERRORGemini側の失敗
503DATABASE_ERROR／GEMINI_API_KEY_MISSING／INVALID_GEMINI_API_KEYDB通信失敗、キー未設定・形式不正

2. 解析画面メッセージ

場面メッセージ
画像未選択画像ファイルを1枚以上選択してください。
未保存の結果なしデータベースへ保存する未保存の解析結果がありません。先に解析してください。
接続不可Backendに接続できませんでした。
保存ボタンデータベースへ保存

3. ログイン・一覧・デモ画面メッセージ

場面メッセージ
未入力ユーザーIDとパスワードを入力してください。
文字数超過ユーザーIDは64文字、パスワードは128文字以内で入力してください。
認証失敗ユーザーIDまたはパスワードが正しくありません。
ロック中ログインの失敗が続いたため、しばらくしてから再度お試しください。
一覧が空保存済みのレシートはありません。
入力不備入力内容を確認してください。

4. ログ方針

  • log/backend.log に出力し、日次でZIPにローテーションする。
  • APIキー・画像本文・個人情報は出力しない（個人情報の置換は件数のみ記録）。
  • 予期しない例外の詳細はログにのみ残し、応答には INTERNAL_ERROR だけを返す。
