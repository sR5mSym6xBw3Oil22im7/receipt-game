環境変数一覧

変数名必須既定値設定先用途・注意
PORT任意8081実行環境Spring Boot の待受ポート。
DB_HOST任意localhostローカル / Render（fromDatabase）PostgreSQL のホスト。
DB_PORT任意5432ローカル / Render（fromDatabase）PostgreSQL のポート。
DB_NAME任意receipt_dbローカル / Render（fromDatabase）データベース名。
DB_USER任意postgresローカル / Render（fromDatabase）DBユーザー。
DB_PASSWORD必須なしローカル / Render（fromDatabase）DBパスワード。未設定では起動できない。
ADMIN_USERNAME必須なしローカル / Render（sync: false）管理者ユーザーID。
ADMIN_PASSWORD_HASH必須なしローカル / Render（sync: false）管理者パスワードのBCryptハッシュ。
SESSION_COOKIE_SECURE任意trueローカル / Render（"true"）セッションCookie・CSRF CookieのSecure属性。
LOGIN_MAX_FAILURES任意5必要時のみログインをロックするまでの連続失敗回数。
LOGIN_LOCK_MINUTES任意15必要時のみロックする時間（分）。

Gemini APIキーは環境変数ではなく、解析の要求ごとに画面から受け取る。

ローカル設定例

reBack/.env.example の内容：

PORT=8081
DB_HOST=localhost
DB_PORT=5432
DB_NAME=receipt_db
DB_USER=postgres
DB_PASSWORD=replace-locally
ADMIN_USERNAME=replace-locally
ADMIN_PASSWORD_HASH=replace-with-bcrypt-hash
SESSION_COOKIE_SECURE=false
# LOGIN_MAX_FAILURES=5
# LOGIN_LOCK_MINUTES=15

Render設定

変数render.yml の設定
ADMIN_USERNAMEsync: false（Renderの画面で値を設定）
ADMIN_PASSWORD_HASHsync: false（Renderの画面で値を設定）
SESSION_COOKIE_SECURE"true"
DB_HOST / DB_PORT / DB_NAME / DB_USER / DB_PASSWORDfromDatabase（receipt-analysis-psl-service の host / port / database / user / password）

管理ルール

  • .env はリポジトリ直下の .gitignore でGitの管理対象外とする。
  • DBパスワード、管理者ユーザーID、管理者パスワードハッシュをリポジトリ・文書・ログに記載しない。
  • HTTPSで提供する環境では SESSION_COOKIE_SECURE を true とする。
