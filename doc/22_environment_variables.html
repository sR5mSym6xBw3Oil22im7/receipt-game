環境変数一覧

名前必須既定説明
GEMINI_API_DEFAULT必須—既定のGemini APIキー。未設定だと起動しない
GEMINI_API_ANALYZE任意DEFAULTレシート解析用
GEMINI_API_MONSTER任意DEFAULTカード生成用
GEMINI_API_PLAYER1 / _PLAYER2任意DEFAULT席ごとの画像カード作成用（PLAYER2はCPUの選択にも使用）
ADMIN_USERNAME必須—管理者ID
ADMIN_PASSWORD_HASH必須—管理者パスワードのBCryptハッシュ
DB_HOST DB_PORT DB_NAME DB_USER—localhost / 5432 / receipt_db / postgresDB接続先
DB_PASSWORD必須—DBパスワード
PORT任意8081待ち受けポート
SESSION_COOKIE_SECURE任意trueローカルのHTTPのみ false
LOGIN_MAX_FAILURES / LOGIN_LOCK_MINUTES任意5 / 15ログイン失敗のロック
MONSTER_WAIT_SECONDS任意90対人の待機秒数。超えるとCPU対戦
MONSTER_ROOM_TTL_MINUTES任意120操作のないルームの失効
MONSTER_AI_ILLUSTRATION任意trueAIによるカード／イラスト生成
MONSTER_TRUST_FORWARDED_FOR任意falseプロキシ背後で true
MONSTER_GEMINI_DAILY_LIMIT任意200キー別の1日のGemini呼出し上限
MONSTER_BACKFILL_ON_STARTUP任意true起動時に、カードのない保存済みレシートへカードを作る
GEMINI_MONSTER_MODEL任意gemini-3.5-flash-liteカード生成のモデル

ローカル設定例

PORT=8081
DB_HOST=localhost
DB_PORT=55432
DB_NAME=receipt_db
DB_USER=postgres
DB_PASSWORD=（DBに設定した値）
ADMIN_USERNAME=（任意の管理者ID）
ADMIN_PASSWORD_HASH=（BCryptハッシュ）
SESSION_COOKIE_SECURE=false
GEMINI_API_DEFAULT=（Gemini APIキー）

reBack/.env.example を reBack/.env にコピーして設定する。.env はGit管理外。OSの環境変数が優先される。

Render設定

  • sync: false：ADMIN_USERNAME、ADMIN_PASSWORD_HASH、GEMINI_API_*（手動で設定）。
  • 固定値：SESSION_COOKIE_SECURE=true、MONSTER_AI_ILLUSTRATION=true、MONSTER_TRUST_FORWARDED_FOR=true。
  • DB_* は fromDatabase で自動設定。

管理ルール

  • 値をリポジトリ、ログ、画面に出さない。
  • 追加・変更したら、本書と reBack/README.md、render.yml を合わせて更新する。
