スモークテストの失敗

項目内容
テストserver.mjs rejects foreign Host, dotfiles, bad encodings and non-GET methods（TC-149）
現象パス「/」へのページ移動で、302 を期待したところ 200 が返った
原因実施時、別に起動していた node reFront/server.mjs（2026-10-14 22:21 起動）がポート5051を使っていた。テストが起動したサーバーはポートを確保できず、テストは起動中の古いプロセスに要求を送っていた。コードの不具合ではない
対応起動中の server.mjs を止めてから再実行する（本書の作成時点では、利用中のプロセスのため止めていない）

3. 確認済み事項

  • 管理API（解析・保存・一覧・詳細・削除）が、未ログイン401・管理者以外403・CSRFなし403になり、拒否された要求ではデータが変わらない。
  • 表にない /api 配下は管理者でも拒否される。ログイン前のCSRFトークンはログイン後に使えない。
  • ログイン失敗が上限に達すると、正しいパスワードでも429になる。
  • 解析ではレシートのテーブルを作らず、SHA-256を返す。保存済みの画像は409。
  • 保存時に個人情報が除去され、除去できなければ保存しない。カードは MONSTER → DEFAULT → 計算式の順で作られる。
  • 2人対戦で、対戦開始前は相手のカードが見えない。待機時間後はコンピュータ対戦になり、AIが失敗したらPOWER最大を選ぶ。
  • カード生成と対戦の計算が、デモの JavaScript と一致する。
  • 危険なSVG・個人情報・画像ボム・偽装ファイル・極端な数値・AIの不正な文字列が拒否または補正される。
  • 直接アクセスはメニューへ転送され、CSS・API・/admin/ は対象外。

4. 実行証跡の取得手順

# バックエンド（結果は reBack/target/surefire-reports/ に出力される）
cd reBack
