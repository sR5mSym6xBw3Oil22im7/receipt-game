機能一覧

ID分類機能名概要利用画面／API実装状態
F-01表示メニューデモ、レシート解析、保存済みレシート確認への入口を表示。管理画面リンクを接続先設定に合わせて書き換える。index.html / index.js実装済み
F-02デモデモ解析架空レシート画像と固定データで解析結果を表示。API・DBは呼び出さない。demo.html / demo.js実装済み
F-03認証ログインユーザーID・パスワードでログインし、セッションを作成。login.html / POST /api/auth/login実装済み
F-04認証ログイン試行制限同じユーザーIDの連続失敗が上限に達したら一定時間ログインを拒否。LoginAttemptLimiter実装済み
F-05認証ログアウトセッションを破棄してログイン画面へ戻る。POST /api/auth/logout実装済み
F-06解析ファイル指定JPEG / PNG / ZIPをファイル選択またはドラッグ＆ドロップで指定。upload.html / app.js実装済み
F-07解析ZIP展開ZIP内のJPEG / PNGをブラウザーで展開。それ以外を含む場合は中断。app.js実装済み
F-08解析Gemini解析画像をGeminiで解析し、行ごとの文字列、構造化データ、SHA-256を返す。DBには登録しない。POST /api/receipts/analyze実装済み
F-09保存解析結果の保存未保存の解析結果をPostgreSQLへ保存。POST /api/receipts/save実装済み
F-10保存重複画像の拒否保存済みの画像（SHA-256一致）の解析・保存を409で拒否。ReceiptTableRepository実装済み
F-11管理一覧保存済みレシートのテーブル名・行数・作成日時を表示。select.html / GET /api/receipts実装済み
F-12管理詳細行番号付きの文字列を表示。select.html / GET /api/receipts/{tableName}実装済み
F-13管理削除チェックしたレシートを確認後に削除。構造化データと画像ハッシュも削除。select.html / DELETE /api/receipts/{tableName}実装済み
F-14運用ヘルスチェック稼働状態をJSONで返却。GET /api/health実装済み

機能間の関連

ログイン→ファイル指定→（ZIP展開）→Gemini解析→保存の順でレシート登録の流れを構成する。保存した結果は一覧・詳細・削除で扱う。デモはこの流れから独立し、メニューから直接利用する。
