1. バックアップ対象

バックアップの対象は GitHub リポジトリのみです。それ以外は対象外とします。

対象要否備考
GitHubリポジトリ（ソース、文書、設定ファイル）対象変更履歴はGitで管理し、GitHubに保管する
データベース（PostgreSQL）対象外DBのバックアップ・リストアは行わない
環境変数/シークレット対象外リポジトリに含めない。別管理（39）
元のレシート画像対象外アプリでは保管しない

2. バックアップ・リストア手順

  • バックアップ：変更をGitHubリポジトリに反映する。
  • リストア：リポジトリを失った場合は git clone で取得し、21 の手順で環境を作り直す。
  • DBのバックアップ・リストアは対象外のため、手順は定めない。

3. 定期メンテナンス

周期作業
四半期依存ライブラリの更新確認（Spring Boot等）と mvn test、APIキーのローテーション検討
随時ログ・ヘルス確認（/api/health）、管理者パスワード変更、不要レシートの削除（自動削除はしない）

実施者は開発者本人。
