環境差分の吸収

  • ブラウザが file:、localhost、127.0.0.1 で開いている場合、config.js はバックエンドURLを http://localhost:8081 とする。それ以外は https://receipt-analysis-b8po.onrender.com とする。
  • Spring Boot は PORT 環境変数を優先し、未設定時は8081とする。
  • local プロファイルでは、セッションCookieとCSRF CookieのSecure属性を無効にし、ログをファイルへ出力する。
  • DB接続先、管理者、Cookie、ログイン制限は環境変数で切り替える。
