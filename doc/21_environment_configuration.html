環境別構成

項目ローカル本番
フロントエンドnode reFront/server.mjs（http://localhost:5051）GitHub Pages
バックエンドmvn spring-boot:run -Dspring-boot.run.profiles=local（http://localhost:8081）Render（Docker）
DBDockerコンテナ receipt-game-db（postgres:16-alpine、55432→5432）Render PostgreSQL（メジャー18）
Cookie Securefalse（local プロファイル）true
接続先の切替reFront/config.js が localhost を検出localhost 以外で本番の接続先

前提ソフトウェア

ソフトウェア版用途
JDK21バックエンド
Maven3.9系ビルド・テスト
Node.jsnode:test が使える版ローカルサーバー・スモークテスト
Docker最新ローカルDB
Gemini APIキー—解析・カード生成（GEMINI_API_DEFAULT は必須）

ローカルポート

ポート用途
5051reFront（固定。バックエンドの「メニューへ戻る」と合わせている）
8081reBack（PORT で変更可）
55432ローカルDB（コンテナの5432）

環境差分の吸収

  • Cookieの Secure 属性は SESSION_COOKIE_SECURE（local プロファイルでは無効）。
  • メニューURLは local プロファイルで http://localhost:5051/index.html。
  • DB接続先は環境変数。テストはH2。
サービス（PostgreSQL・バックエンド・フロントエンド）を再起動・停止する前に、実際に何で動いているかを docker ps、ps などで確認する。このプロジェクトのDBはDockerコンテナ receipt-game-db であり、ホストの postgresql.service とは無関係。再起動は docker restart receipt-game-db。
