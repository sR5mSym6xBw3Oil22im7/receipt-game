環境別構成

項目ローカルテスト（mvn test）本番
フロントエンドnode reFront/server.mjs（http://localhost:5051）—（スモークテストはファイルを直接読む。server.mjs のテストは5051で起動）GitHub Pages
バックエンドmvn spring-boot:run -Dspring-boot.run.profiles=local（http://localhost:8081）Spring Boot Test（MockMvc）Render Web Service（Docker、Free）
DBDocker receipt-game-db（postgres:16-alpine、55432→5432）などH2（PostgreSQL互換、メモリ）Render PostgreSQL 18（Free）
GeminireBack/.env のキー呼ばない（差し替え）Render の環境変数
プロファイルlocal（Cookie の Secure 無効、ログをファイル、メニューは localhost:5051）testなし（既定）

前提ソフトウェア

ソフトウェア版用途
Java（JDK）21（21.0.12 で確認）ビルド・実行
Maven3.9系（3.9.12 で確認）ビルド・テスト
Node.js22系（22.22.2 で確認）server.mjs、スモークテスト
PostgreSQL16以上ローカルのDB
Docker任意ローカルのDB、イメージの確認
ブラウザーDecompressionStream に対応した最新のもの画面の確認

ローカルポート

ポート用途
5051reFront/server.mjs（固定。config.js の「メニューへ戻る」の移動先と同じ）
8081バックエンド（PORT で変更可）
5432PostgreSQL の既定（DB_PORT）。Docker の receipt-game-db を使う場合はホスト側 55432

環境差分の吸収

  • config.js：file:・localhost・127.0.0.1 で開いたら http://localhost:8081 と http://localhost:5051/index.html、それ以外は本番のURL。
  • application.yml：${変数:既定値} で環境変数を参照し、spring.config.import で reBack/.env を読み込む（OSの環境変数が優先）。
  • application-local.yml：Cookie の Secure を無効にし、ログを log/backend.log に出し、メニューのURLを localhost:5051 にする。
  • pom.xml：spring-boot-maven-plugin の既定プロファイルを local にしている。
  • render.yml：SESSION_COOKIE_SECURE=true、MONSTER_TRUST_FORWARDED_FOR=true、DB接続情報はデータベースから設定。
