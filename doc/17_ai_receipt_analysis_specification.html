1. 目的

Geminiでレシート画像の文字列と構造化データを取り出す（解析）。保存済みレシートの内容から、モンスターの名前・技・説明・イラストを作る（カード生成）。AIが使えないときも計算式で継続する。

2. 対象画像

  • JPEG / PNG、5 MiB以下、25,000,000画素以下。
  • JPEG/PNGだけのZIPはブラウザーで展開して1枚ずつ送る。

3. 解析の処理フロー

画像検査型・サイズ・画素
→
SHA-256重複予約
→
GeminiJSONスキーマ指定
→
正規化lines＋structuredData
→
確認・保存管理者
  • 応答に回転指定（90/180/270度）があれば画像を回して読み直し、行数の多い方を採用する（12,000,000画素超は回さない）。
  • GEMINI_API_ANALYZE のキーで失敗し、特定のコードのときは GEMINI_API_DEFAULT で再試行する。

4. Gemini設定

項目値
解析モデルgemini.receipt-model（gemini-3.5-flash-lite）
カード生成モデルGEMINI_MONSTER_MODEL（既定 gemini-3.5-flash-lite）
タイムアウト180秒
キーGEMINI_API_DEFAULT（必須）、_ANALYZE、_MONSTER、_PLAYER1、_PLAYER2
応答形式JSONスキーマ指定

5. 応答スキーマと正規化

  • 店種は スーパー／コンビニ／ドラッグストア／飲食店／その他、明細カテゴリーは 食料品／日用品／飲食／交通・移動／その他 の許可リストに丸める。
  • 件数・文字数・金額は検証ルール（第11章）の範囲に収める。

6. カード生成

順内容
1GEMINI_API_MONSTER でパラメータとSVGイラストを生成
2失敗なら GEMINI_API_DEFAULT で再試行
3両方失敗なら、計算式の値と代替イラスト

計算式（アルゴリズム版数2）

画像のSHA-256先頭32bitを乱数の種とし、金額・最高額・文字数・品数・購入時刻・日付を0〜1に正規化して能力値を計算する。金額の影響はどの能力値でも25%以下。

HP   = 200 + floor(500 × (0.25fA + 0.30fC + 0.15fN + 0.15fW + 0.15r0))
ATK  =  40 + floor(100 × (0.25fM + 0.25fC + 0.15fT + 0.15fW + 0.20r1))
DEF  =  30 + floor( 80 × (0.15fA + 0.30fN + 0.20fC + 0.15fW + 0.20r2))
SPD  =  40 + floor( 60 × (0.35fT + 0.20fW + 0.15fC + 0.10fN + 0.20r3))
LUCK =   5 + floor( 20 × (0.50r4 + 0.25fW + 0.25fC))
POWER = floor(HP/5 + ATK + DEF + SPD/2 + LUCK×2)
要素定義
fAmin(合計,30000)/30000
fMmin(最大明細額,10000)/10000
fCmin(文字数,600)/600
fNmin(明細数,20)/20
fT|購入時−12|/12
fW(日−1)/30×0.7＋週末0.3
区分ルール
属性明細カテゴリー別の金額合計が最大のもの。飲食→炎、食料品→土、日用品→風、交通・移動→雷、その他→無
レア度N（274以下）／R（275〜）／SR（315〜）／SSR（345〜）
店種ボーナススーパー HP×1.1、コンビニ SPD×1.1、ドラッグストア DEF×1.1、飲食店 ATK×1.1、その他 LUCK+3
ラッキー合計がゾロ目または末尾777／購入時刻の時と分が同じ／7のつく日 → ATK・DEF×1.1、LUCK+10

7. AI出力の安全化

  • 名前はカタカナ12文字以内、説明は80文字以内。URL風の文字列は採用しない。
  • SVGは許可リストで検証（30,000字以内、300要素以内、深さ12以内、サイズ1000以内。スクリプト・外部参照・イベント属性・コメントは不可）。不合格なら代替イラスト。
  • POWER・レア度・店種ボーナスはAIの値を使わずサーバーで再計算する。

8. 解析不能・障害時

状況動作
文字が読み取れない422 NO_TEXT_FOUND
キー未設定／形式不正503 GEMINI_API_KEY_MISSING／INVALID_GEMINI_API_KEY
キー拒否401 GEMINI_API_KEY_REJECTED
上限超過429 GEMINI_QUOTA_EXCEEDED／GEMINI_DAILY_LIMIT
その他のGemini障害502 GEMINI_API_ERROR。カード生成では計算式へ切替
