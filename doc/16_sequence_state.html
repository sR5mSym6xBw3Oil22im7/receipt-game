3. コンピューター対戦

  • 作成から90秒（MONSTER_WAIT_SECONDS）以内に参加がなければ、次のアクセスで mode=CPU に切替えて配布（advance）。
  • プレイヤーが決定するとCPUが非同期で手札を引き、Gemini（PLAYER2キー）または最大POWERで1枚を決定。
  • CPUが選んだ理由（cpuReason）は結果に表示。AI不使用時は「自動で選びました」。

4. ルームの状態遷移

WAITINGP2待ち
→
SELECTINGカード選択（round+1）
→
BATTLE結果確定
→
CLOSED退出/期限/放置
遷移契機
WAITING → SELECTINGP2が参加／待機時間経過でCPU化
SELECTING → BATTLE両者が決定（CPUは非同期で決定）
BATTLE → SELECTINGrematch（現在のroundを指定したときのみ。round+1して配り直す）
任意 → CLOSEDleave、またはTTL（120分操作なし）。閉じたルームは10分保持

対戦結果は monster_battle に保存されるが、ルーム削除時に連動して消える（ON DELETE CASCADE）。

5. カードの状態遷移

（なし）
→
DRAFT解析後に非同期作成
→
ACTIVE保存で有効化
  • DRAFTのまま24時間経過 → 破棄（10分ごとの掃除）。
  • レシート削除 → カード削除。
  • 起動時、カードのない保存済みレシートへ生成（バックフィル）。
