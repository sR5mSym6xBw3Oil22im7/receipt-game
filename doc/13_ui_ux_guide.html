1. 方針

  • reFront/styles.css（共通）は日替わりテーマ導入後も変更しない。見た目の差し替えは theme/base.css と theme/tNN.css による上書きで行う。
  • 画面の動きはCSSのtransition/animationのみ。prefers-reduced-motion で止まるようにする。
  • HTMLから読み込むCSS/JSのURLには ?v= でバージョンを付け、内容を変えたら更新する。
