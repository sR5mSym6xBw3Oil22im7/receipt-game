2. ファイル責務

ファイル責務
index.html / index.jsメニューのDOM構造。index.js は管理画面へのリンクを APP_CONFIG.ADMIN_BASE_URL に合わせて設定する。
demo.html / demo.jsデモ画面。固定データから結果の行を作り、0.9秒後に表示する。
config.js接続先URL（window.APP_CONFIG）の設定と、金貨の装飾SVGの描画。
login.html / login.jsログインフォーム、ログイン要求、ステータス別メッセージ、遷移先の決定。
upload.html / app.js解析画面。ファイル指定、ZIP展開、解析・保存の呼び出し、段階表示、状態管理。
select.html / select.js一覧の取得・表示、詳細表示、選択削除。
admin-api.jsCSRFトークン付きの fetch（adminFetch）、ログアウト、「メニューへ戻る」リンクの設定。
styles.css全画面の配色、レイアウト、フォーム、一覧、レスポンシブ。

3. 状態管理

状態保存先用途削除
analyzedReceiptsJavaScript変数（app.js）画像ごとの解析結果（lines、sha256、structuredData、保存済みかどうか）を保持。ファイル変更時、全件保存成功時。
analysisReadyJavaScript変数（app.js）全画像の解析が成功したかを示し、保存ボタンの表示を決める。解析開始時・失敗時にfalse。
busyJavaScript変数（app.js）解析・保存の多重実行を防ぐ。処理終了時にfalse。
selectedTableNamesJavaScript変数（select.js）削除対象として選択したテーブル名。削除成功時に該当分を削除。
Gemini APIキー入力欄のみ解析要求ごとに送信。ブラウザーのストレージには保存しない。「入力を消去」ボタン、ページを閉じる。

4. API呼出し

画面API方式
ログインPOST /api/auth/loginJSON。adminFetch がCSRFトークンを付ける。
解析POST /api/receipts/analyzemultipart（file、geminiApiKey）。画像1枚ごとに送信。210秒で中断。
解析POST /api/receipts/saveJSON（lines、sha256、structuredData）。未保存の結果ごとに送信。30秒で中断。
一覧GET /api/receipts、GET /api/receipts/{tableName}一覧と詳細の取得。
一覧DELETE /api/receipts/{tableName}選択した件ごとに送信。
解析・一覧POST /api/auth/logoutログアウト後に /admin/login.html へ移動。

adminFetch は GET・HEAD・OPTIONS 以外の要求の前に GET /api/auth/csrf でトークンを取得し、X-XSRF-TOKEN ヘッダーに設定する。送信は credentials: "same-origin" で行う。

5. 実装完了内容

  • メニュー、デモ、ログイン、解析、一覧（詳細パネルを含む）の5画面。
  • JPEG / PNG と ZIP の受付、ドラッグ＆ドロップ、ブラウザー内のZIP展開。
  • 解析・保存の時間制限と、15秒ごとの経過表示。
  • APIキーに関するエラー時の入れ替え案内。
  • 保存失敗時に、保存済みの結果を残して未保存分だけ再試行できる動作。
  • reFront/ と static/admin/ の管理画面スクリプトの一致を確認するスモークテスト。
