2. ファイル責務

ファイル責務
config.jsページを開いた場所（file:／localhost／127.0.0.1かどうか）で、API_BASE_URL・ADMIN_BASE_URL・SELECT_URL・PUBLIC_BASE_URL を決める。reFront 版だけ DEMO_URL・GAME_URL を持つ。
index.jsメニューのリンク先を config.js の値に置き換える。
direct-access-guard.js<head> の先頭で読み込み、同じサイトの reFront/ 配下からのリンクでなければ index.html へ location.replace する。reFront/ は index.html に正規化する。
theme/theme.js日付からテーマを選び、base.css・tNN.css・フォントを読み込む。読み込み中は document.write で描画を止めるlinkを書き、ちらつきを防ぐ。3:00に自動で切り替える。
admin-api.jsadminFetch（POST・DELETE の前に /api/auth/csrf でトークンを取り X-XSRF-TOKEN に付ける）、ログアウト、「メニューへ戻る」の設定。
login.js入力チェックとログイン要求、結果に応じた移動。
app.jsファイル選択・ドロップ、ZIP展開、解析要求（210秒）、結果表示、保存要求（30秒）。
select.js一覧・詳細・まとめて削除。
game.jsロビー〜結果の画面制御、対戦APIの呼び出し、ポーリング、対戦の再生。席を sessionStorage に保存する。
fx.js / fx.css演出（ルームコード、席、待機リング、カードの登場、攻撃・必殺技・KO、結果、明細）。本番とデモで共通。
back-link.js対戦・デモの「メニューへ戻る」の移動先を決める。
demo.js / engine.js / mock-data.jsデモの画面制御、バックエンドと同じ計算（カード生成・個人情報の除外・対戦）、架空のレシート。

3. 状態管理

画面状態保持場所
解析analyzedReceipts（番号・行・SHA-256・構造化データ・保存済みか）、analysisReady、busyメモリ（ページ内の変数）
一覧selectedTableNames、openTableNameメモリ
対戦code・token・seatsessionStorage（キー monster-seat）。再読み込みのときだけ席に戻る
対戦room・field・選択中のカードID・再生の進み具合・速度メモリ
テーマなし（日付から毎回計算。?theme= も保存しない）—
ログインセッションCookie（HttpOnly、SameSite=Lax）とCSRF Cookie（XSRF-TOKEN）ブラウザーのCookie（サーバーが管理）

Gemini APIキーやパスワードはブラウザーのストレージに保存しない（スモークテストで検査）。

4. API呼出し

画面呼び出し方式
ログインPOST /api/auth/loginadminFetch（JSON）
解析POST /api/receipts/analyze、POST /api/receipts/saveadminFetch（multipart／JSON）、AbortController で打ち切り
一覧GET /api/receipts、GET /api/receipts/{tableName}、DELETE /api/receipts/{tableName}adminFetch。削除は1件ずつ順に送る
共通POST /api/auth/logoutadminFetch
対戦/api/monster/rooms 配下fetch（cache: no-store）、X-Seat-Token。待機1秒、カード選択1.5秒、結果2秒ごとに GET /{code}

5. 実装完了内容

  • APIから受け取った文字列は、管理画面では textContent で表示する。対戦画面はテンプレート文字列でHTMLを組み立てるため、APIの文字列はすべて esc() でエスケープしてから埋め込む（fx.js は textContent）。
  • HTMLから読み込むCSS・スクリプトには ?v= のバージョン文字列を付ける。
  • 管理画面のスクリプトはバックエンドからだけ配信する（reFront/ には置かない）。config.js・styles.css・theme/ は reFront/ にも同じものを置く。
  • テーマを導入した後も styles.css は変更せず、theme/base.css と tNN.css で上書きする。
