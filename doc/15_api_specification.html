2. 管理系API

POST /api/auth/login

{"username": "admin", "password": "（パスワード）"}
200: {"redirect": "/admin/menu.html"}
401: {"message": "ユーザーIDまたはパスワードが正しくありません。"}
429: {"message": "ログインの失敗が続いたため、しばらくしてから再度お試しください。"}

POST /api/receipts/analyze

multipart/form-data  file : image/jpeg または image/png（最大5 MiB）
200 OK
{
  "lines": ["（読み取った1行目）", "…"],
  "sha256": "（64桁の16進数）",
  "structuredData": {
    "storeName": "…", "branchName": null, "storeCategory": "スーパー",
    "purchasedAt": "2026-08-03T10:53:00", "totalAmount": 1082,
    "paymentMethod": "…", "receiptNumber": null,
    "items": [{"name": "…", "category": "食料品", "quantity": 1, "unitPrice": 218, "amount": 218}]
  }
}

POST /api/receipts/save

{"lines": ["…"], "sha256": "（解析で返された値）", "structuredData": {…}}
200 OK
{"tableName": "receipt_（32桁16進）", "lineCount": 12, "lines": ["…"], "sha256": "…"}
入力制約（ValidationRules）値
lines 件数/1行長1000件／500文字
items 件数200件
名称255文字
カテゴリー50文字
支払方法 / レシート番号100文字
金額±1,000,000,000
NUL文字不可

GET /api/receipts、GET/DELETE /api/receipts/{tableName}

GET 一覧: [{"tableName": "receipt_…", "lineCount": 12, "createdAt": "…"}]（テーブル名の降順）
GET 詳細: {"tableName","lineCount","createdAt","lines":[{"lineNo":1,"text":"…"}]}
DELETE: 204（レシート・構造化データ・ハッシュ・カードも削除）。無い/不正な名前は404 RECEIPT_NOT_FOUND

flip{"index":0〜8}FlipResponse {card, field}

select{"cardId":N}RoomView（双方決定で battleReady=true）
