1. API一覧

メソッドパス認可内容
GET/api/health公開稼働確認
GET/api/auth/csrf公開CSRFトークンを返す
GET/api/auth/session公開ログイン状態を返す
POST/api/auth/login公開（CSRF必要）ログイン
POST/api/auth/logoutログイン済み（CSRF必要）ログアウト（204）
POST/api/receipts/analyze管理者（CSRF必要）画像を解析（DBには登録しない）
POST/api/receipts/save管理者（CSRF必要）解析結果を保存
GET/api/receipts管理者保存済みレシートの一覧
GET/api/receipts/{tableName}管理者保存済みレシートの詳細
DELETE/api/receipts/{tableName}管理者（CSRF必要）削除（204）
POST/api/monster/rooms公開ルーム作成（P1）
POST/api/monster/rooms/{code}/join公開ルーム参加（P2）
GET/api/monster/rooms/{code}席トークンルームの状態
GET/api/monster/rooms/{code}/field席トークン配られたレシート・手札・画像カード
POST/api/monster/rooms/{code}/shuffle席トークン配り直し
POST/api/monster/rooms/{code}/flip席トークンレシートをめくる
POST/api/monster/rooms/{code}/image-card席トークン画像からカードを作る
POST/api/monster/rooms/{code}/select席トークンカードを決定
GET/api/monster/rooms/{code}/battle席トークン対戦結果
POST/api/monster/rooms/{code}/rematch席トークン再戦
POST/api/monster/rooms/{code}/leave席トークン退出（204）

上の表にない /api 配下のパスは、管理者を含めて拒否する。対戦APIはCSRFの対象外で、応答はすべて Cache-Control: no-store。

2. 認証API

POST /api/auth/login

項目内容
要求Content-Type: application/json、X-XSRF-TOKEN。本文 {"username": "…", "password": "…"}
成功（200）{"redirect": "/admin/menu.html"}。セッションIDを変更し、ログイン前のCSRFトークンを破棄
失敗401 {"message": "ユーザーIDまたはパスワードが正しくありません。"}、429 {"message": "ログインの失敗が続いたため、…"}、400 VALIDATION_ERROR

GET /api/auth/csrf・GET /api/auth/session

API応答
/api/auth/csrf{"token": "…"}（XSRF-TOKEN Cookie も設定）
/api/auth/session管理者なら {"authenticated": true, "username": "…"}、それ以外は {"authenticated": false}

3. POST /api/receipts/analyze

項目内容
要求multipart/form-data、パート file（JPEG / PNG）
成功（200）
{
  "lines": ["スーパー○○", "2026/10/03(土) 10:12", "..."],
  "sha256": "64桁の16進数",
  "structuredData": {
    "storeName": "…", "branchName": "…", "storeCategory": "スーパー",
    "purchasedAt": "2026-10-03T10:12:00", "totalAmount": 3480,
    "paymentMethod": "…", "receiptNumber": "…",
    "items": [{"name": "牛乳", "category": "食料品", "quantity": 1, "unitPrice": 198, "amount": 198}]
  }
}
主なエラー400 EMPTY_FILE、413 FILE_TOO_LARGE／IMAGE_TOO_LARGE、415 UNSUPPORTED_MEDIA_TYPE、409 DUPLICATE_RECEIPT_IMAGE、422 NO_TEXT_FOUND／EMPTY_ANALYSIS_RESULT／INVALID_ANALYSIS_RESULT、429 GEMINI_QUOTA_EXCEEDED、401 GEMINI_API_KEY_REJECTED、503 GEMINI_API_KEY_MISSING、400／502 GEMINI_API_ERROR

4. POST /api/receipts/save

項目内容
要求application/json。{"lines": [...], "sha256": "…", "structuredData": {…}}（解析の応答をそのまま送る）
成功（200）{"tableName": "receipt_＜32桁＞", "lineCount": n, "lines": [置換後の行], "sha256": "…"}
主なエラー400 EMPTY_RECEIPT／INVALID_IMAGE_HASH／VALIDATION_ERROR、409 DUPLICATE_RECEIPT_IMAGE（未解析・保存済み）、422 PERSONAL_INFO_CHECK_FAILED／INVALID_DATA、503 DATABASE_ERROR

5. GET /api/receipts・GET /api/receipts/{tableName}・DELETE

API応答
GET /api/receipts[{"tableName": "…", "lineCount": n, "createdAt": "ISO 8601"}, …]（テーブル名の降順）
GET /api/receipts/{tableName}{"tableName", "lineCount", "createdAt", "lines": [{"lineNo": 1, "text": "…"}, …]}。形式違い・存在しない場合は404 RECEIPT_NOT_FOUND
DELETE /api/receipts/{tableName}204。構造化データ・ハッシュ・カードも削除。404 RECEIPT_NOT_FOUND

6. モンスターレシート対戦API

API要求応答（200）
POST /roomsなしSeatResponse {code, seat: "P1", token, room}
POST /rooms/{code}/joinなしSeatResponse {code, seat: "P2", token, room}
GET /rooms/{code}X-Seat-TokenRoomView {code, seat, status（WAITING／SELECTING／BATTLE／CLOSED）, mode（HUMAN／CPU）, round, waitSecondsLeft, opponentJoined, opponentState（WAITING／SELECTING／CONFIRMED）, opponentUnresponsive, youConfirmed, battleReady, notice}
GET /rooms/{code}/fieldX-Seat-TokenFieldView {round, receipts[{index, selected, receipt}], shuffleVisible, canShuffle, hand[CardView], imageCard, selectedCardId, confirmed, handLimit}
POST /rooms/{code}/shuffleX-Seat-TokenFieldView
POST /rooms/{code}/flip{"index": n}FlipResponse {card, field}
POST /rooms/{code}/image-cardmultipart fileImageCardResponse {card, reused, message, field}
POST /rooms/{code}/select{"cardId": n}RoomView
GET /rooms/{code}/battleX-Seat-TokenBattleView {round, battleSeed, first, log[{round, actor, target, skill, skillName, damage, crit, elem, hpAfter}], winner（P1／P2／DRAW）, reason（KO／JUDGE）, finalHp, cards, receipts, mode, cpuReason}
POST /rooms/{code}/rematch{"round": n}RoomView
POST /rooms/{code}/leaveX-Seat-Token204

CardView は {id, name, element, rarity, hp, atk, def, spd, luck, power, skillName, skillPower, lucky, flavor, storeCategory, source, svg}。画像ハッシュ・テーブル名・行テキストは応答に含めない。相手のカードとレシートは BattleView でだけ返す。ReceiptView は {storeCategory, storeName, branchName, purchasedAt, receiptNumber, items[{name, quantity, unitPrice, amount}], totalAmount, paymentMethod}。

7. エラーレスポンス

{"code": "DUPLICATE_RECEIPT_IMAGE", "message": "同じレシート画像は既にPostgreSQLへ登録されています。", "timestamp": "2026-10-15T10:00:00+09:00"}

Spring Securityが拒否した場合（未ログインの401、権限なしの403、CSRFなしの403、表にない /api）は本文の形が異なる。未ログインで /admin/ 配下を開いた場合は /admin/login.html へリダイレクトする。コードの一覧は「エラー処理・メッセージ一覧」に示す。
