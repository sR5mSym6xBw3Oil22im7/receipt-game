1. ファイル責務

ファイル責務変更時の注意
reFront/index.html, demo.htmlメニュー、デモのDOM構造JavaScriptが参照するIDを変更する場合はスクリプトも同期する。
static/admin/*.htmlログイン、解析、一覧のDOM構造スモークテストが要素や属性を検査するため、テストも確認する。
app.js, select.js, login.js, admin-api.js管理画面の処理reFront/ と static/admin/ の両方を同じ内容に更新する。
config.js接続先URL、装飾描画render.yml のサービス名を変えた場合は接続先URLも変更する。
styles.css全画面のスタイルreFront/ と static/admin/ の両方にある。
SecurityConfig.java認証・認可新しいAPIは明示的に許可しない限り拒否される。
application.yml設定値秘密情報に既定値を書かない。
README.md, doc/説明・開発文書仕様を変えたら記載も更新する。

2. コーディング規約

  • 文字コードはUTF-8、改行はLF、末尾に改行を入れる（.editorconfig）。
  • Javaは config / controller / service / repository / dto / exception の責務で分ける。依存はコンストラクタで受け取る。
  • 要求・応答のデータは record で定義する。
  • 業務エラーは ReceiptException（HTTPステータス、英大文字スネークケースのコード、日本語メッセージ）で表す。
  • SQLの値はプレースホルダーで渡す。テーブル名を連結する場合は ReceiptTableName の検証を通す。
  • JavaScriptはフレームワークを使わない。APIから受け取った文字列は textContent で表示する。
  • 管理APIの呼び出しは adminFetch を使う。
  • Gemini APIキーをブラウザーのストレージやサーバーに保存しない。
  • CSS・スクリプトの読み込みURLには ?v= のバージョン文字列を付け、内容を変えたら更新する。

3. ローカル確認

PostgreSQLを起動し、環境変数を設定してバックエンドを起動します。フロントエンドは reFront/index.html をブラウザーで開きます。

export DB_PASSWORD='（ローカルDBのパスワード）'
export ADMIN_USERNAME=admin
export ADMIN_PASSWORD_HASH='（BCrypt形式のハッシュ）'
cd reBack
mvn spring-boot:run -Dspring-boot.run.profiles=local

# 別ターミナルで自動テスト
cd reBack && mvn test
cd .. && node --test reFront/test/smoke.test.mjs
自動テストではGemini呼び出しをスタブに置き換えています。実際の解析は、有効なGemini APIキーを使ってブラウザーで確認します。

4. 変更手順

  1. 変更対象と影響範囲（画面、API、DB、認可）を特定する。
  2. テストを追加・修正する。
  3. 実装する。管理画面スクリプトを変えた場合は reFront/ の複製も更新する。
  4. 読み込みURLの ?v= を更新する。
  5. mvn test とスモークテストを実行する。
  6. ブラウザーで操作を確認する。
  7. README と開発文書を更新する。

5. レビュー観点

観点確認内容
認可新しいパスが意図した権限で保護されているか。
CSRF更新系の要求が adminFetch を使っているか。
秘密情報APIキー、パスワード、DB情報がコード・ログ・コミットに含まれていないか。
SQL値がプレースホルダーか、テーブル名が検証済みか。
XSS外部からの文字列を innerHTML に入れていないか。
同期reFront/ と static/admin/ の複製が一致しているか。
テスト自動テストがすべて合格しているか。
