1. 構成（reBack/render.yml）

リソース設定
Webサービス名前 receipt-game、runtime: docker、rootDir: reBack、dockerfilePath: ./Dockerfile、plan: free、healthCheckPath: /api/health
PostgreSQL名前 receipt-analysis-psl-service、plan: free、postgresMajorVersion: "18"、ipAllowList: []（外部接続不可）
DB接続DB_HOST/PORT/NAME/USER/PASSWORD を fromDatabase で自動注入
固定の環境変数SESSION_COOKIE_SECURE=true、MONSTER_AI_ILLUSTRATION=true、MONSTER_TRUST_FORWARDED_FOR=true

サービス名はRenderの公開ホスト名（<name>.onrender.com）を決めるため、reFront/config.js と常に一致させる。

2. イメージ（reBack/Dockerfile）

  • ビルド：maven:3.9.11-eclipse-temurin-21-alpine（mvn -DskipTests package）。
  • 実行：eclipse-temurin:21-jre-alpine、非rootユーザー app、EXPOSE 8081。
  • 起動：java -XX:MaxRAMPercentage=70 -XX:+ExitOnOutOfMemoryError -jar app.jar。

3. フロント

  • GitHub Pagesでリポジトリを公開。メニュー：…/reFront/index.html。
  • reFront/config.js は localhost 以外で本番の接続先（https://receipt-game.onrender.com）を使う。
  • 404.html が存在しないURLをメニューへ転送。

4. DBの初期化

手動のDDL実行は不要。アプリが CREATE TABLE IF NOT EXISTS で作成する（14）。

5. ネットワーク・セキュリティ

  • HTTPSはRenderが終端。アプリは forward-headers-strategy=framework でスキームを復元しHSTSを付与。
  • DBは内部接続のみ。
  • Gemini APIへは外向きHTTPSが必要。

6. 費用・上限

Renderのプラン料金・無料枠の制約（無活動時の停止、DBの保持期間など）は変更されうるため、最新のRender公式情報を確認してください。現在の利用プランは render.yml のとおり無料プラン（plan: free）です。
