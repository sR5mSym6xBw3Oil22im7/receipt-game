システム構成図

利用者ブラウザHTML/CSS/JavaScript
HTTPS
GitHub PagesreFront：メニュー・デモ
Render Web ServiceJava 21 / Spring Boot API ＋ 管理画面（/admin）
↓ JDBC　　　↓ HTTPS（Google Gen AI SDK）
Render PostgreSQLレシートデータ
Gemini APIレシート画像の解析

構成要素

要素役割通信
ブラウザ画面表示、ZIP展開、解析・保存・一覧・削除の操作GitHub Pages・Renderから画面を取得し、RenderへAPI通信
GitHub PagesreFront配下の静的ファイル（メニュー・デモ）を配信HTTPS
Render Web ServiceREST API、認証・認可、管理画面の配信、解析・保存処理HTTPS、JDBC、外部HTTPS
PostgreSQL読み取った文字列、構造化データ、画像のSHA-256を保存JDBC
Gemini API画像から文字列と構造化データを生成Google Gen AI SDK（google-genai）

API経路

経路内容
ブラウザ → Render /api/auth/*CSRFトークン取得、ログイン、ログイン状態確認、ログアウト
ブラウザ → Render /api/receipts/*解析、保存、一覧、詳細、削除（管理画面から同一オリジンで呼び出す）
Render → Gemini API画像とプロンプトを送信し、JSONスキーマに沿った応答を受け取る
Render → PostgreSQLテーブル作成、登録、参照、削除
Render（ヘルスチェック）→ /api/healthrender.yml の healthCheckPath
