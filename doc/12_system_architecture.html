システム構成図

ブラウザープレイヤー／管理者（PC・スマートフォン）
↓ HTTPS
GitHub PagesreFront/ メニュー・動画・テーマ
Render Web ServicereBack/ Spring Boot：API＋/admin＋/game＋/demo
↓ JDBC（内部接続） ／ ↓ HTTPS
Render PostgreSQLレシート・カード・ルーム
Google Gemini API画像解析・カード生成・CPUの選択

ローカルでは、reFrontを node reFront/server.mjs（ポート5051）、reBackを mvn spring-boot:run（ポート8081）、DBをDockerコンテナ receipt-game-db（ホスト55432→5432）で動かす。

構成要素

要素配置備考
静的フロントGitHub Pagesconfig.js が localhost 以外で本番の接続先を使う
バックエンドRender（Docker、rootDir: reBack）サービス名 receipt-game。ヘルスチェック /api/health
DBRender PostgreSQL（receipt-analysis-psl-service）外部接続不可（ipAllowList: []）
AIGoogle Gemini APIキーは環境変数。用途別に5種

API経路

経路プロトコル保護
ブラウザー → GitHub PagesHTTPS—
ブラウザー → バックエンドHTTPS管理：セッション＋CSRF／対戦：席トークン
バックエンド → DBJDBC（Render内部）DBユーザー・パスワードは環境変数
バックエンド → GeminiHTTPSAPIキー（用途別）、タイムアウト180秒
