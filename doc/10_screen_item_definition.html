ログイン入力項目

項目要素ID型必須桁数備考
ユーザーIDuser-idtext○64文字以内空白だけは不可。送信名 username
パスワードpasswordpassword○128文字以内送信名 password

解析入力項目

項目要素ID型必須条件備考
レシート画像receipt-file-1file○JPEG / PNG（5 MiB以下）またはZIP（50 MiB以下）ドロップゾーン drop-zone からも指定できる。名前は receipt-file-name-1 に表示

解析結果表示項目

項目出所表示備考
見出し画面レシート画像nZIPは展開した順に番号を振る
行ごとの文字列POST /api/receipts/analyze の linespre に改行区切りで表示（textContent）保存時には個人情報を置換した文字列が保存される
SHA-256同 sha256表示しない保存要求にそのまま送る
構造化データ同 structuredData表示しない保存要求にそのまま送る

保存済み一覧・詳細表示項目

画面項目出所形式
一覧テーブル名tableNamereceipt_ ＋ 32桁の16進数
一覧行数lineCount「n行」
一覧登録日時createdAttoLocaleString("ja-JP")、なければ「日時不明」
詳細テーブル名・行数・登録日時GET /api/receipts/{tableName}バッジ
詳細行lines[].lineNo, lines[].text「n.」と文字列

対戦画面の入力・表示項目

区分項目要素ID・出所形式・条件
M01ルームコードjoin-code6文字。英大文字（I・Oを除く）と2〜9。小文字は大文字にして送る
M02ルームコードroom-code（code）6文字
M02残り秒数waitSecondsLeft整数秒
M03配られたレシートGET …/field の receipts[]index、selected（めくり済み）、receipt（店舗カテゴリー、店名、支店名、購入日時 yyyy-MM-dd HH:mm、レシート番号、商品［名前・数量・単価・金額］、合計、支払方法）
M03手札hand[]（最大 handLimit=3）カード表示
M04画像image-inputJPEG / PNG、5 MiB以下
M03/M04選択中のカードchosen-info名前（属性・レア度・POWER n）
カード名前・属性・レア度name, element, rarityカタカナ12文字以内、炎／土／風／雷／無、N／R／SR／SSR
カード能力値hp, atk, def, spd, luck, power整数
カード必殺技skillName, skillPower「必殺技：名前 ×1.50」（小数2桁）
カード説明文・店舗カテゴリー・作成元flavor, storeCategory, sourcesource は ANALYZE／PLAYER1／PLAYER2
カードイラストsvgdata:image/svg+xml の img
