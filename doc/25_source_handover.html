3. ビルド確認手順

  1. cd reBack && mvn test が全件成功すること。
  2. node --test reFront/test/smoke.test.mjs の結果を確認（現状の結果は 29）。
  3. cd reBack && mvn -DskipTests package で target/receipt-backend-0.0.1-SNAPSHOT.jar ができること。
  4. docker build で reBack/Dockerfile がビルドできること。
