SCR-01 メニュー

領域内容
見出し「Monster Receipt Battle」「モンスターレシート対戦」、説明文
メニューモンスターレシート対戦（ログイン不要）／モンスターレシート対戦（デモ）／管理者ログイン（「管理者」バッジ）の順に並べる。
動画操作ガイド（標準版）・操作ガイド（簡易版）・プロモーション映像1・2 を2行2列で表示（幅560px以下は1列）。
フッター「— Monster Receipt Battle —」と本日のデザイン名

リンク先は HTML に本番URLを書いておき、index.js が config.js の値で上書きする（ローカルでは http://localhost:8081 側へ向く）。

SCR-02 動画視聴

16:9 の video 要素で mp4 を再生する（guide6min → video/manual/guide6min.mp4、guide3min → guide3min.mp4、pv1 → video/pv/pv01.mp4、pv2 → pv02.mp4）。上部に「← メニューへ戻る」を置く。styles.css は変えず、ページ内の style 要素で動画用の指定を行う。

SCR-03 管理者ログイン

領域内容
入力ユーザーID（maxlength 64、autocomplete=username）、パスワード（maxlength 128、autocomplete=current-password）
操作「ログイン」ボタン。Enterでも送信
結果表示login-status（aria-live=polite）に失敗理由を表示。成功時は管理者メニューへ移動

SCR-04 管理者メニュー

「レシート解析」「保存済みレシートを確認する」の2項目と、「← メニューへ戻る」「ログアウト」を置く。未ログインで開くとログイン画面へリダイレクトされる。

SCR-05 レシート解析

領域内容
進行表示画像を選ぶ → 解析する → 内容を確認 → データベースへ保存 の4段階（現在の段階を強調）
ファイル選択ドロップゾーン（クリックでファイル選択、ドラッグ＆ドロップ可）。accept は image/jpeg, image/png, .zip。選択したファイル名を表示
操作「解析」（解析中は「解析中...」で無効）、「データベースへ保存」（未保存の解析結果があるときだけ表示）
状態表示status（aria-live=polite）。ZIPは「画像n/m を解析中です」、15秒ごとに経過秒数を表示
解析結果画像ごとに「レシート画像n」と行ごとの文字列（pre）。保存済みは is-saved で区別

保存がすべて成功すると、画面を初期状態に戻して次の解析を始められるようにする。失敗した場合は解析結果と保存ボタンを残し、再試行できるようにする。

SCR-06 保存済みレシート一覧

領域内容
ツールバー件数表示（list-status）と「チェックしたレシートを削除」（1件以上チェックで有効、0件なら非表示）
一覧行ごとにチェックボックス、テーブル名、行数、登録日時、「参照」ボタン。0件なら「レシートを解析・保存すると、ここに表示されます。」
詳細パネルテーブル名・行数・登録日時のバッジと、行番号付きの文字列。「閉じる」で閉じる。開いている行は is-open で強調

SCR-07 モンスターレシート対戦

区分画面の構成
M01 ロビー「ルームを作る」（P1）と、「ルームに参加する」（6桁のコード入力欄＋「参加」、エラー表示 join-error）。前のルームが閉じられた理由を lobby-notice に表示。
M02 待機ルームルームコード（大きく表示）と「コピー」、P1・P2の席の状態（あなた／相手プレイヤー／コンピュータ／待機中）、残り秒数のリング、「ロビーへ戻る」。
M03 レシートを選ぶ配られたレシート（最大9枚。店舗カテゴリー・店名・日時・レシート番号・商品表・合計・支払方法）と「▶ このレシートを選ぶ」、「シャッフル」（条件を満たすときだけ表示）、手札（最大3枚のカード）。
M04 レシート画像から作るドロップゾーン（JPEG / PNG・5 MiBまで）、状態表示、作ったカードのプレビュー。手札が3枚・決定済みのときは使えない。
M03/M04 共通席のバッジ、相手の状態（選択中／確定・内容は非公開）、無応答の警告、選択中のカード（名前・属性・レア度・POWER）と「このカードで決定」、「ロビーへ（ルームを閉じる）」。
M05 対戦左に自分、右に相手のカードとHPバー、battleSeed、コンピュータの選択理由、速度切替・スキップ、行動ログ（必殺技・属性有利／不利・会心のタグ）。
M06 結果YOU WIN! ／ YOU LOSE… ／ DRAW の表示、勝因（KO決着・回数／20ラウンド終了で判定）と battleSeed、2枚のカード、バトル明細、選ばれた2枚の元レシート、「同じルームで再戦」「ロビーへ」。

カードは、名前・レア度・属性・ラッキー表示・イラスト（SVGを data: URI の img で表示）・HP／ATK／DEF／SPD／LUCK・必殺技と倍率・説明文・店舗カテゴリー・作成元（保存済みレシート／P1が画像から生成／P2が画像から生成）を表示する。

SCR-08 デモ

SCR-07 と同じ区分（ロビー〜結果）を持つ。データは mock-data.js の架空のレシート、計算は engine.js（バックエンドと同じ計算式）で行う。待機ルームには「（デモ用）相手プレイヤーが参加した」ボタンがあり、押さなければ12秒でコンピュータ対戦になる。画像からのカード作成は、画像のSHA-256から作った架空のレシートで模擬する（送信しない）。

レスポンシブ・アクセシビリティ

  • レイアウトは container（is-wide あり）とカードで構成し、狭い画面では1列にする。
  • 状態やエラーの表示には aria-live、role=status、role=alert を付ける。入力エラーは aria-invalid と aria-describedby で関連づける。
  • カードの選択ボタンには aria-pressed、タブには role=tab と aria-selected を付ける。
  • 動き（カードの登場、HPバー、カットイン、テーマの装飾）はCSSのtransition／animationで行い、prefers-reduced-motion で止める。
  • 装飾用の要素（演出レイヤー、矢印、点滅）は aria-hidden=true にする。
