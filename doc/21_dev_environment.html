1. 必要なもの

ツール版用途
JDK21バックエンド
Maven3.9 系（Dockerfileは 3.9.11）ビルド・テスト
Node.jsnode:test が使える版（ESM）フロントのローカルサーバー・スモークテスト
Docker任意の最新ローカルPostgreSQL（postgres:16-alpine）
Gemini APIキー—解析・カード生成（GEMINI_API_DEFAULT は必須）

2. 手順

  1. リポジトリを取得する。
  2. PostgreSQLを用意する。例：docker run -d --name receipt-game-db -e POSTGRES_PASSWORD=<任意> -e POSTGRES_DB=receipt_db -p 55432:5432 postgres:16-alpine（ポート55432→5432）。
  3. reBack/.env.example を reBack/.env にコピーし、値を設定する（下記3章）。
  4. バックエンドを起動する。
  5. フロントエンドを起動する。
  6. http://localhost:5051/index.html を開く。
# バックエンド（http://localhost:8081。reBack/.env が必要）
cd reBack && mvn spring-boot:run -Dspring-boot.run.profiles=local

# フロントエンド（リポジトリ直下。http://localhost:5051/index.html）
node reFront/server.mjs

3. reBack/.env の項目

キーローカルの目安
PORT8081
DB_HOST / DB_PORT / DB_NAME / DB_USERlocalhost / 55432（Dockerの場合）/ receipt_db / postgres
DB_PASSWORDDBに設定した値
ADMIN_USERNAME任意の管理者ID
ADMIN_PASSWORD_HASHBCryptハッシュ（平文は置かない）
SESSION_COOKIE_SECUREfalse（ローカルのHTTP用。local プロファイルでも無効化される）
GEMINI_API_DEFAULT必須
GEMINI_API_PLAYER1/2、MONSTER、ANALYZE任意（未設定なら DEFAULT を使う）
.env の値はコミットしない。localhost 以外のフロントは本番の接続先を使う（reFront/config.js）。

4. テスト実行

cd reBack && mvn test                         # H2を使うのでPostgreSQL不要
node --test reFront/test/smoke.test.mjs      # リポジトリ直下で実行。5051番ポートを使う

5. 注意

  • サービス（PostgreSQL・バックエンド・フロント）を再起動/停止する前に、実際に何で動いているかを確認する（docker ps、ps、/proc/<pid>/cgroup）。systemdだと決めつけない。
  • このプロジェクトのDBはDockerコンテナ receipt-game-db。ホストのsystemdの postgresql.service は無関係。再起動は docker restart receipt-game-db。
  • server.mjs はポート5051固定。既に5051で別プロセスが動いているとスモークテストの結果が影響を受けるので、テスト前に確認する。
