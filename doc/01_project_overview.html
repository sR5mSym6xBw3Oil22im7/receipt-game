1. プロジェクト概要

項目内容
プロジェクト名レシート解析システム（リポジトリ名：receipt-analysis）
システム種別静的フロントエンド＋REST API＋PostgreSQLによるレシート解析Webシステム
AI解析Google Gemini API（モデル：gemini-3.5-flash-lite）
フロントエンド公開先https://sr5msym6xbw3oil22im7.github.io/receipt-analysis/reFront/index.html
バックエンド公開先https://receipt-analysis-b8po.onrender.com
バックエンド版数0.0.1-SNAPSHOT（pom.xml）

2. 開発目的

  • レシート画像から、印字された文字列と店舗・商品などの構造化データをAIで取り出す。
  • 解析結果を管理者が確認してからPostgreSQLへ保存し、保存済みデータを一覧・詳細・削除で管理できるようにする。
  • 同じ画像の二重登録を防ぐ。
  • Gemini APIキーを持たない閲覧者も、デモで操作の流れを確認できるようにする。

3. 対象ユーザー

ユーザー利用目的
閲覧者メニュー画面とデモ画面で、レシート解析の操作の流れを確認する。ログイン・APIキーは不要。
管理者ログインし、レシート画像の解析、解析結果の保存、保存済みレシートの参照・削除を行う。解析にはGemini APIキーが必要。
開発者ローカル環境で起動し、API・DB保存・テストを確認する。

4. 成果物

  • 公開フロントエンド一式（reFront/）
  • Spring Boot REST API と管理画面（reBack/）
  • PostgreSQLのテーブル定義（アプリ実行時に作成）
  • Gemini APIによるレシート解析機能
  • Dockerfile と Render Blueprint（render.yml）
  • JUnitテスト、Node.jsスモークテスト
  • README（ルート、reBack、reFront）
  • 開発・設計・テスト・リリース文書（本書を含むdoc/）

5. 開発工程

要件定義目的・機能・対象範囲を整理
設計画面・API・DB・外部連携・セキュリティを設計
実装（コーディング）フロントエンド、バックエンド、AI解析を実装
テスト単体・結合テスト、スモークテスト、手動確認
リリースGitHub PagesとRenderへ公開

6. 開発範囲

デモ、管理者ログイン、レシート画像（JPEG / PNG、およびそれらをまとめたZIP）の解析、解析結果の保存、保存済みレシートの一覧・詳細・削除を対象とする。画像ファイルの保存、Gemini APIキーの保存、構造化データの画面表示・編集、集計機能は対象外とする。
