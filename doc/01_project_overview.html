1. プロジェクト概要

項目内容
プロジェクト名モンスターレシート対戦（リポジトリ名：receipt-game）
システム種別静的フロントエンド＋REST API＋PostgreSQLによる、レシート解析・カード対戦Webシステム
AIGoogle Gemini API（モデル：gemini-3.5-flash-lite）
フロントエンド公開先https://sr5msym6xbw3oil22im7.github.io/receipt-game/reFront/index.html
バックエンド公開先https://receipt-game.onrender.com
バックエンド版数0.0.1-SNAPSHOT（pom.xml）

2. 開発目的

  • レシート画像をGoogle Geminiで解析し、確認後にPostgreSQLへ保存する。
  • 保存済みレシートから、世界に一枚のモンスターカードを生成し、2人（または対コンピューター）で対戦できるようにする。
  • 同じレシート画像からは必ず同じ名前・能力値のカードができるようにし、勝敗はサーバーで計算して改ざんを防ぐ。
  • AIが使えないときも、計算式の値と代替イラストでゲームを継続できるようにする。
  • ログイン不要のデモで、Gemini APIキーを持たない閲覧者にも流れを体験してもらう。

3. 対象ユーザー

ユーザー利用目的
プレイヤーログイン不要。ルームコードで友人と対戦する。相手が90秒以内に来なければコンピューターと対戦する。
管理者（1名）ログインし、レシート画像の解析、保存、保存済みレシートの参照・削除を行う。保存したレシートがカードになる。
閲覧者メニュー、デモ、動画で作品の内容を確認する。
開発者ローカルで起動し、API・DB保存・テストを確認する。

4. 成果物

  • メニューの静的ページ（reFront/）と日替わりテーマ10種、動画ページ4種
  • Spring Boot REST API、管理画面、対戦画面、デモ画面（reBack/）
  • PostgreSQLのテーブル定義（アプリが実行時に作成）
  • Gemini APIによるレシート解析とカード生成
  • Dockerfile と Render Blueprint（render.yml）
  • JUnitテスト、Node.jsスモークテスト
  • README（ルート、reBack、reFront）と、本書を含む開発文書（doc/）

6. 開発範囲

管理者ログイン、レシート画像（JPEG / PNG、およびそれらだけのZIP）の解析・保存・一覧・詳細・削除、モンスターカードの生成、2人対戦／コンピューター対戦、デモ、日替わりテーマを対象とする。課金、ユーザーアカウント、ランキング、3人以上の対戦、画像ファイルの保存、Gemini APIキーの保存は対象外とする。
