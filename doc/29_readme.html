モンスターレシート対戦

レシート画像を Google Gemini で解析して PostgreSQL に保存し、保存済みレシートからモンスターカードを作って対戦するWebシステムです。管理者がレシートを登録し、プレイヤーはログインせずにルームコードで2人対戦（相手が来なければコンピュータ対戦）ができます。リポジトリのREADMEと同じ内容を、文書の形式でまとめています。

公開URL

対象URL
メニューhttps://sr5msym6xbw3oil22im7.github.io/receipt-game/reFront/index.html
バックエンドhttps://receipt-game.onrender.com（対戦 /game/index.html、デモ /demo/index.html、管理 /admin/login.html）

主な機能

機能利用者内容
モンスターレシート対戦だれでもルームを作る／コードで参加する。配られたレシートからカードを呼び出し、1枚を決めて対戦する。画像からカードを作ることもできる
デモだれでも架空のレシートで一通りの流れを体験する（通信しない）
レシート解析・保存管理者JPEG / PNG（ZIP可）を解析し、確認してから保存する。個人情報は保存前に取り除く
一覧・詳細・削除管理者保存済みレシートを確認・削除する（カードも削除される）
日替わりデザインだれでも10テーマが毎日3:00（日本時間）に切り替わる

必要環境

  • Java 21、Maven
  • PostgreSQL（ローカルは Docker でも可）
  • Node.js（フロントエンドの配信とテスト）
  • Gemini APIキー（GEMINI_API_DEFAULT）

ローカル起動

# 1. 設定ファイルを用意する（DB_PASSWORD、ADMIN_USERNAME、ADMIN_PASSWORD_HASH、GEMINI_API_DEFAULT を編集）
cd reBack
cp .env.example .env

# 2. バックエンドを起動する（http://localhost:8081）
mvn spring-boot:run -Dspring-boot.run.profiles=local

# 3. 別のターミナルで、リポジトリ直下からフロントエンドを起動する（http://localhost:5051/index.html）
node reFront/server.mjs

テスト

cd reBack && mvn test                      # H2を使うのでPostgreSQLは不要
node --test reFront/test/smoke.test.mjs   # リポジトリ直下で実行（ポート5051を空けておく）

主要API

メソッドパス認可
GET/api/health公開
GET／POST/api/auth/csrf・session・login・logout公開（logout はログイン済み）
POST/api/receipts/analyze・save管理者＋CSRF
GET／DELETE/api/receipts、/api/receipts/{tableName}管理者（DELETE は CSRF）
GET／POST/api/monster/rooms 配下公開（作成・参加）／席トークン X-Seat-Token

詳細は「API仕様書」を参照。

注意事項

  • Gemini APIキー、管理者のパスワードハッシュ、DB接続情報をリポジトリに含めない（reBack/.env は Git の管理外）。
  • 本番は HTTPS で動かし、SESSION_COOKIE_SECURE を true にする（既定値）。
  • Render の Free プランは停止から起動するまでに時間がかかる。
  • 新しいAPIを足すときは SecurityConfig の認可設定と README の API 表を更新する。
