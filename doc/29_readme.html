モンスターレシート対戦

レシート画像をGoogle Geminiで解析してPostgreSQLに保存し、保存済みレシートからモンスターカードを作って対戦するWebシステムです。詳細はリポジトリ直下の README.md、reBack/README.md、reFront/README.md を参照してください。

公開URL

対象URL
メニューhttps://sr5msym6xbw3oil22im7.github.io/receipt-game/reFront/index.html
バックエンドhttps://receipt-game.onrender.com

主な機能

  • 管理者によるレシート解析・確認・保存・一覧・削除
  • 保存済みレシートからのモンスターカード生成
  • ルームコードによる2人対戦、90秒でコンピューター対戦
  • 架空レシートのデモ、日替わりテーマ10種

必要環境

  • JDK 21、Maven 3.9、Node.js、Docker、Gemini APIキー

ローカル起動

docker run -d --name receipt-game-db -e POSTGRES_PASSWORD=<任意> -e POSTGRES_DB=receipt_db -p 55432:5432 postgres:16-alpine
cp reBack/.env.example reBack/.env          # 値を設定する（Git管理外）
cd reBack && mvn spring-boot:run -Dspring-boot.run.profiles=local     # http://localhost:8081
node reFront/server.mjs                      # リポジトリ直下 http://localhost:5051/index.html

テスト

cd reBack && mvn test
node --test reFront/test/smoke.test.mjs

主要API

第15章を参照。管理：/api/auth/*、/api/receipts/*。対戦：/api/monster/rooms/*。

注意事項

  • Gemini APIキー、パスワードハッシュ、DB接続情報をリポジトリに含めない。
  • reBack/.env はGit管理外。
  • 管理画面JS・テーマは reBack と reFront で同期が必要（片方だけ直さない）。
