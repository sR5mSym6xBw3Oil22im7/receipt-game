Gemini API連携

用途使うキー失敗時
レシート解析ANALYZE → DEFAULTエラーを管理画面に表示
カード生成MONSTER → DEFAULT計算式の値と代替イラスト
画像からのカード作成PLAYER1／PLAYER2 → DEFAULT計算式で継続
コンピューターのカード選択PLAYER2 → DEFAULTPOWERが最大のカードを選ぶ
  • キーは画面から入力させず、DBにも保存しない。ログにも出さない。
  • キー別に1日200回まで（MONSTER_GEMINI_DAILY_LIMIT）。超えると429。
  • プロンプトにも、個人情報を出力しないよう明記している。

PostgreSQL連携

  • 接続先は DB_HOST DB_PORT DB_NAME DB_USER DB_PASSWORD。Renderでは fromDatabase で自動設定。
  • SQLのタイムアウトは20秒。DBエラーは503 DATABASE_ERROR。

公開環境連携

  • reFront/config.js は localhost 以外で https://receipt-game.onrender.com を使う。Renderのサービス名を変えたら同時に更新する。
  • app.frontend.menu-url は、直接アクセスの転送先（GitHub Pagesのメニュー）。
