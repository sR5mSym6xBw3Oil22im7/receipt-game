Gemini API連携

項目内容
SDKcom.google.genai:google-genai 1.67.0。要求ごとに Client を作り、try-with-resources で閉じる
呼び出しclient.models.generateContent(model, content, config)。config は responseMimeType=application/json、responseSchema、candidateCount=1
キーの選び方解析：ANALYZE → DEFAULT。カード（保存時）：MONSTER → DEFAULT。画像カード：PLAYER1／PLAYER2。コンピュータ：PLAYER2。用途別が空なら DEFAULT
上限の管理MonsterRateLimiter.tryAcquireGemini がキー名（MONSTER・DEFAULT・PLAYER1・PLAYER2）ごとに1日の回数を数える（既定200、JSTで日付が変わると0に戻る）。管理者の解析は数えない
例外の扱いApiException はステータスで分類（429→上限、401・403・api key→キー拒否、その他4xx→400、5xx→502）。SDKが通常の例外で返した場合もメッセージから上限・認証の失敗を判定する
ログモデル・MIMEタイプ・画像サイズ・例外名・APIのステータスを残す。キー・画像・プロンプトの中身は残さない

PostgreSQL連携

項目内容
接続jdbc:postgresql://${DB_HOST:localhost}:${DB_PORT:5432}/${DB_NAME:receipt_db}、ユーザー ${DB_USER:postgres}、パスワード ${DB_PASSWORD}（必須）
プールSpring Boot 既定（HikariCP）
タイムアウトspring.jdbc.template.query-timeout: 20s
トランザクション保存・削除・ルーム操作・再点検で TransactionTemplate／@Transactional を使う
テストH2（PostgreSQL互換）。application.yml の接続先はテストでは使わない
ローカルDocker コンテナ receipt-game-db（postgres:16-alpine、ホスト55432→5432）。再起動は docker restart receipt-game-db
