55. 納品ドキュメント対応表

1. はじめに

  • 対象：管理者（1名）。画面：/admin/*。
  • メニュー（reFront/index.html）→「管理者ログイン」から入る。

2. ログイン／ログアウト

  1. ユーザーID（64字以内）とパスワード（128字以内）を入力して[ログイン]。
  2. 5回失敗すると15分ロックされる。
  3. 終了時は各画面の[ログアウト]。

3. レシート解析・保存

  1. 「レシート解析」を開く。
  2. JPEG/PNG（5 MiB以内）またはZIP（JPEG/PNGのみ）を選ぶ（ドラッグ&ドロップ可）。
  3. [解析]を押す。画像ごとに進捗が表示される（1枚最大約210秒）。
  4. 結果（行文字列・店名・購入日時・合計・明細）を確認する。誤読があれば保存しない。
  5. 個人情報が含まれていないか確認し、[データベースへ保存]を押す。保存時に個人情報は「（非表示）」に置換される。
  6. 「同じレシート画像は既に登録されています」は重複。保存不要。
解析だけではDBに登録されません。保存を押して初めて登録され、モンスターカードが有効になります。

4. 保存済みレシートの確認・削除

  1. 「保存済みレシートを確認する」を開く。
  2. 一覧から行を選ぶと詳細（行文字列）が表示される。
  3. 削除は、チェックして[チェックしたレシートを削除]。カードも一緒に削除される。元に戻せない。
