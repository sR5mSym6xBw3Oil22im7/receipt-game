4. 情報漏えい（疑い）時

  1. 該当キー/パスワードを即時無効化し再発行（39）。
  2. 影響範囲（Gemini利用、DBのレシート）を確認。
  3. 利用者・関係者へ告知する（個人情報が含まれる場合は、個人情報保護法に基づく報告の要否を判断）。
  4. 再発防止策を障害報告書に記載。
