2. 画像ファイルチェック

確認箇所チェック条件メッセージ
画面ファイル未選択画像ファイルを1枚以上選択してください。
画面先頭バイトがJPEG（FF D8 FF）・PNG（89 50 4E 47 0D 0A 1A 0A）のどちらでもないJPEGまたはPNG画像、またはZIPファイルを選択してください。
APIファイルが空400 EMPTY_FILE「画像ファイルを選択してください。」
API5,242,880バイトを超える413 FILE_TOO_LARGE「画像ファイルのサイズが上限を超えています。」
APIContent-Typeが image/jpeg・image/png 以外415 UNSUPPORTED_MEDIA_TYPE「JPEGまたはPNG画像を指定してください。」

3. ZIPファイルチェック

条件処理・メッセージ
フォルダー読み飛ばす。
終端レコードが見つからないZIPファイルを読み込めません。ZIPが壊れている可能性があります。
暗号化されたファイルZIP内のファイル「名前」は暗号化されています。処理を中断しました。
拡張子が .jpg / .jpeg / .png 以外ZIP内にJPEG/PNG以外のファイル「名前」があるため、処理を中断しました。
無圧縮・Deflate以外の圧縮方式ZIP内のファイル「名前」は未対応の圧縮方式です。処理を中断しました。
展開後のサイズ不一致、または中身がJPEG / PNGでないZIP内のファイル「名前」がJPEG/PNG画像ではないため、処理を中断しました。
画像が1枚もないZIPファイルにレシート画像がありません。
DecompressionStream が使えないこのブラウザはZIP解凍に対応していません。最新のブラウザで再実行してください。

4. Gemini APIキーチェック

確認箇所条件処理
画面前後の空白を除いて空APIを呼ばず「Gemini APIキーを入力してください。」を表示し、入力欄にフォーカス。
画面入力欄の最大長maxlength="512"。
API前後の空白を除いて空400 GEMINI_API_KEY_MISSING
API前後の空白を除いて512文字超400 INVALID_GEMINI_API_KEY

5. エラー表示方式

  • 画面のメッセージは各画面の状態表示欄（aria-live="polite"）へ表示する。
  • Gemini APIキーに関するエラー（上限超過、キー拒否、未入力、形式不正）では、APIキー欄にフォーカスして全選択する。
  • 解析・保存で401・403を受けた場合は、再ログイン・再読み込みを促す文言に置き換える。
  • ZIPの不正は、該当するファイル名を含めて表示する。
